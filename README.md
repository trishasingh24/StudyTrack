# StudyTrack — Java Study Hours Tracker

A Java command-line application that helps college students record, organize, and monitor their study hours.

## The Problem

College students often struggle to keep track of how much time they spend studying different subjects. Without an organized record, it can be difficult to identify study habits and understand how time is distributed across courses.

StudyTrack aims to solve this problem by providing a simple way to record study sessions and monitor study hours.

## How It Works

StudyTrack allows users to:

- Record a study session with a subject, date, and duration.
- Save study sessions in a local CSV file.
- Load previously saved study records.
- View total study hours for each subject.

The application uses a command-line menu to guide users through its features.



## MVP Scope

The initial version focuses on three main features:

1. Recording study sessions.
2. Saving and retrieving study records.
3. Calculating and displaying study hours by subject.

## Tech Stack

- Language: Java
- Libraries: Scanner, ArrayList, BufferedReader, PrintWriter, and LocalDate
- Development Environment: Visual Studio Code and JDK
- Data Storage: CSV file
- Version Control: Git and GitHub
- External APIs: None

## Setup

## Usage

The planned command-line interface will provide the following options:

1. Add Study Session
2. View Study Sessions
3. View Study Statistics
4. Exit

Users will be able to record study sessions and view their total study hours for different subjects.
